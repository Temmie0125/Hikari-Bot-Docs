# 音游查分 · Phigros

基于 [phi-plugin](https://github.com/Catrong/phi-plugin) 的 Phigros 查分模块，提供上游插件的全部标准功能：成绩查询、RKS/Best 分表、曲目图鉴与别名、段位、猜曲游戏等。在此基础上，本 Bot 额外扩展并接管了**谱面预览**与**谱面文件提取**两个功能（详见下文）。

## 绑定

查分类功能需要先绑定你的 Phigros 账号，凭据为游戏的 **sessionToken（会话码）**。两种绑定方式：

### 方式一：扫码绑定（推荐）

发送 `#phi bind qrcode`，机器人会返回二维码，使用 **TapTap 扫码**即可自动获取会话码并完成绑定，无需手动操作。

### 方式二：手动绑定

自行获取 sessionToken 后直接发送 `#phi bind <会话码>` 绑定。获取方法可发送 `#phi tk help` 查看指引。

| 命令 | 说明 |
| ---- | ---- |
| `#phi bind qrcode` | TapTap 扫码绑定（推荐） |
| `#phi bind <会话码>` | 使用手动获取的 sessionToken 绑定 |
| `#phi tk help` | 查看 sessionToken 获取指引 |
| `#phi update` | 手动刷新成绩数据 |
| `#phi unbind` | 解除绑定 |

::: warning 会话码安全
sessionToken 相当于账号凭证，**务必通过私聊发送给机器人**，切勿在群聊中透露。详见[隐私政策](/about/privacy)。
:::

## 常用命令

| 命令 | 说明 |
| ---- | ---- |
| `#phi help` | 查看完整命令帮助（以机器人内帮助为准） |
| `#phi info` | 个人成绩概览 |
| `#phi b19` / `#phi pgr` | Best19 / RKS 分表 |
| `#phi <曲名>` | 查询单曲成绩与曲绘，支持曲名别名与模糊搜索 |
| `#phi score <曲名>` | 单曲成绩查询 |
| `#phi song` | 曲目图鉴 |
| `#phi alias <曲名>` | 查询曲目别名（支持别名提案公投） |

此外还有段位查询、RKS 排行榜、历史 b30、年度总结、猜曲游戏、主题市场、货币系统等玩法，完整列表以 `#phi help` 输出为准。

## 谱面预览

渲染并返回一张**完整谱面预览图**：

```txt
#phi预览 <曲名> [难度]
```

| 参数 | 说明 |
| ---- | ---- |
| 曲名 | 支持曲名、别名、模糊搜索；多结果时会返回编号列表供选择 |
| 难度 | 可选，`EZ` / `HD` / `IN` / `AT` / `SP` / `LY`，默认 `IN` |

- 示例：`#phi预览 狂喜蘭舞 IN`、`#phi preview Spasmodic`
- 预览图渲染完成后会缓存，同一谱面重复请求秒回；
- 谱面更新或元数据变更后缓存自动失效并重新渲染。

## 谱面文件提取

打包发送指定谱面的**可玩文件**（音乐、曲绘、谱面、信息文件），官谱会**自动转换为 RPE 格式**，可直接导入 Re:PhiEdit 等模拟器：

```txt
#phi谱面 <曲名> <难度>
```

难度为**必填**（`EZ` / `HD` / `IN` / `AT` / `SP` / `LY`），用空格隔开。示例：

```txt
#phi谱面 狂喜蘭舞 IN
#phi file 玩具狂奏曲終焉 EZ
```

返回的压缩包内包含 `music.ogg`、`illustration.png`、`<难度>.json`（RPE 谱面）与 `info.txt`，文件名为「曲名 - 难度.zip」。转换结果会缓存，谱面更新后自动重新转换。

::: danger 使用限制
谱面文件（含音乐与曲绘素材）版权归曲目原作者与 Pigeon Games（鸽游）所有，**仅供你个人学习、研究谱面使用**。禁止滥用和外传：不得二次分发、公开传播提取的文件，不得用于任何商业用途或他人服务。提取即视为已阅读并同意上述限制。
:::

### 提取限制

| 限制 | 说明 |
| ---- | ---- |
| 次数限制 | **官谱每人每天限提取 1 次**；自定义曲库曲目不消耗次数 |
| 版权受限曲目 | 应版权方要求，部分曲目（含 LIMITED 标记）**仅提供谱面预览，不开放文件提取** |
| 私聊提取 | 需先添加机器人为好友 |
| 改谱 `--all-tap` | 在命令任意位置附加 `--all-tap`，可将 Hold 以外的音符全部替换为 Tap（保留 Hold），用于练习；该参数需要**主人或群管理员**权限，或在谱面提取白名单内。改谱产物仅在压缩包内标记「(All Tap)」（难度显示为 `Tap Lv.?`），服务器磁盘上始终保持原版谱面 |

::: tip 模拟器兼容性
由于各模拟器对 RPE 格式的适配存在差异，如果谱面在模拟器中出现异常，请及时向管理员反馈以便修正转换流程。
:::

## 注意事项

- 查分类命令均需先[绑定](#绑定)；
- phi-plugin 会尝试自动拉取最新存档；如果查询结果与游戏内不一致，请尝试手动执行 `#phi update`，或检查游戏内的存档同步状态是否正常；
- 别名查询支持社区维护的曲目别名，也可以通过别名提案参与公投；
- 查询频率过高可能触发限制，请合理使用。

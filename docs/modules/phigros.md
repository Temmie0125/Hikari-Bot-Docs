# 音游查分

<!-- TODO: 按插件实际命令修改本页内容；如接入其他音游，可复制本页改名 -->

查询 Phigros 游戏成绩、曲绘、best 数据等。

## 绑定

查询前需要先绑定你的游戏账号：

| 命令 | 说明 |
| ---- | ---- |
| `phi bind <会话码>` | 绑定 Phigros 会话码 |
| `phi unbind` | 解除绑定 |

::: warning 会话码安全
会话码相当于账号凭证，仅用于查询成绩，请勿泄露给他人。
:::

## 命令列表

| 命令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `phi b19` | 查询 Best19 数据 | `@Hikari phi b19` |
| `phi info` | 查询个人成绩概览 | `@Hikari phi info` |
| `phi <曲名>` | 查询单曲成绩与曲绘 | `@Hikari phi 歌名` |

## 注意事项

- 需要先[绑定](#绑定)才能使用查询命令；
- 游戏服务器数据同步可能有延迟；
- 查询频率过高可能触发限制。

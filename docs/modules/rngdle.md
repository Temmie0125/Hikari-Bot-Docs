# 每日随机数

复刻 [rngdle.com](https://www.rngdle.com/) 的每日数字游戏：每人每天一次机会，掷出一个 `0 ~ 1,000,000` 的随机数。机器人会分析这个数字的趣味性质——回文、质数、顺子、连击、梗数……每种性质对应一枚**徽章**，徽章分值（EP 熵点）相加得到本次总分，再换算成全服百分位评级。每天 0 点重置，第二天又是全新的数字。

## 命令列表

命令不区分大小写，`#RNGdle` 也可简写为 `#RNG`。

| 命令 | 说明 |
| ---- | ---- |
| `#RNGdle` / `#RNG` | 掷出今天的随机数（每人每天一次，每日 0 点重置） |
| `#RNGdle统计` | 查看个人累计 EP、最佳纪录与徽章收集情况 |
| `#RNGdle日榜` | 今日最佳数字与当日玩家抽取排行 |
| `#RNGdle总榜` | 全服累计 EP 排行 |
| `#RNGdle徽章` | 全部徽章图鉴与收集进度 |
| `#RNGdle帮助` | 查看机器人内的命令帮助 |

### 玩法提示

- 数字越稀有，命中徽章的分值越高：徽章按单枚分数分为普通 / 稀有 / 罕见 / 史诗 / 传说 / 神话；总评级按全服百分位划分，从废铁一路到神话；
- 同一族（判定相似）的徽章只取**最高分**计入 EP，其余以「已收集」收录进图鉴——长期游玩就是在收集徽章；
- 想看今天谁的手气最好，发送 `#RNGdle日榜`；想看全场谁肝得最狠，发送 `#RNGdle总榜`。

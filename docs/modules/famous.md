# 名场面

<!-- TODO: 按插件实际命令修改本页内容 -->

随机发送经典「名场面」图片，为群聊增加乐趣。

## 命令列表

| 命令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `名场面` | 随机发送一张名场面图片 | `@机器人 名场面` |
| `名场面列表` | 查看可用名场面列表 | `@机器人 名场面列表` |
| `名场面 <名称>` | 指定查看某个名场面 | `@机器人 名场面 某某` |

## 使用示例

发送：

```txt
@机器人 名场面
```

机器人回复一张随机图片，并附带「再来一张」「查看列表」按钮，点击按钮即可继续操作。

## 注意事项

- 图片来自网络或维护者收集，仅供娱乐；
- 刷新过快可能触发频率限制，稍等片刻再试。

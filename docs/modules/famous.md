# 名场面

一个基于**关键词**的图片收集与调用系统：为每个「名场面」建立一个关键词，群员随时向关键词**投稿**图片，也随时**发送关键词**随机调用——常用于收集群员经典发言截图、专题表情包等。

::: warning 适用范围
本功能**仅在官方群和私聊（好友单聊）中开放**：关键词内容关联特定群员，在其他群内调用容易引起困惑。如需体验，请[添加机器人好友](/about/)私信使用，或在[官方群](/about/)内使用。
:::

## 快速上手

::: tip 典型流程
① 主人创建关键词 → ② 群员投稿图片 → ③ 群员发关键词随时调用
:::

```txt
@Hikari #create 光辉时刻          ← 主人创建关键词
@Hikari #add 光辉时刻 （同时附上图片） ← 群员投稿
@Hikari 光辉时刻                   ← 随机调用一张
光辉时刻 2                        ← 调用指定编号（免@开启时可直接发送）
```

## 命令列表（所有人可用）

| 命令 | 说明 |
| ---- | ---- |
| `关键词` | 直接发送关键词或别名，**随机**调用一张图片 |
| `关键词 <编号>` | 调用指定编号的图片，如 `光辉时刻 2` |
| `#add <关键词>` | 投稿图片，需**同时附上图片**或**引用一条带图的消息** |
| `#list <关键词> [页码]` | 查看该关键词的图片列表（预览图） |
| `#名场面帮助` | 查看机器人内的命令帮助 |

## 命令列表（主人）

| 命令 | 说明 |
| ---- | ---- |
| `#create <关键词>` | 创建关键词 |
| `#add <关键词>` | 同上，主人也可投稿 |
| `#del <关键词> <编号>` | 删除指定编号的图片 |
| `#del <关键词> all` | 删除该关键词下全部图片；若关键词因此变空，会被顺带移除（含关联别名） |
| `#drop <关键词>` | **彻底移除**关键词：全部图片、目录与关联别名一并删除 |
| `#名场面删除关键词 <关键词>` | 同 `#drop` |
| `#setalias <关键词> <别名>` | 为关键词设置别名 |
| `#名场面设置别名 <关键词> <别名>` | 同 `#setalias` |
| `#delalias <别名>` | 删除别名 |
| `#名场面删除别名 <别名>` | 同 `#delalias` |
| `#blacklist add <词汇>` | 将词汇加入黑名单 |
| `#blacklist remove <词汇>` | 将词汇移出黑名单 |
| `#名场面黑名单添加/删除 <词汇>` | 同上，中文写法 |
| `#偷取` / `#steal` | 将附带（或引用）的图片保存到表情包库（不进入名场面关键词目录） |

## 使用示例

### 投稿图片

发送 `#add 光辉时刻` 并**在同一消息中附上图片**；或者直接**引用（回复）**一条带图片的消息发送该命令。添加成功后会返回关键词与编号：

```txt
@Hikari #add 光辉时刻
[附带一张图片]
→ 添加成功！关键词【光辉时刻】编号 3
```

### 调用图片

直接发送关键词即可随机获取一张（无需 `#` 前缀）；在消息后加编号可以指定图片：

```txt
@Hikari 光辉时刻      → 随机一张 + 操作按钮
光辉时刻 2           → 编号为 2 的那张
```

在官方 QQ Bot 中，图片下方会附带快捷按钮：

- **再来一张**：点击立即再随机一张；
- **查看列表**：点击自动在输入框填入列表命令，发送后即可查看。

### 查看列表

`#list 光辉时刻` 会返回**拼贴预览图**：每页 15 张，按编号排列，附页码信息；也支持指定页码 `#list 光辉时刻 2`。官方 QQ Bot 中列表下方有「上一页 / 下一页」按钮，翻到边界时会提示「已经是第一页 / 最后一页啦～」。

## 关键词与别名规则

- 关键词与别名**不区分大小写**，所有命令均可使用别名，效果等同于关键词本身；
- 长度**不超过 10 个字**；
- 不能包含 `\ / : * ? " < > |` 等字符，也不能以空格或点开头/结尾；
- 别名不能与现有关键词或其他别名重名。

## 黑名单

黑名单中的词汇（含作为**子串**出现时）不允许被创建为关键词、不允许投稿，直接调用时也会被**静默忽略**（机器人不会回复）。默认黑名单由维护者设置。如果你发现某个关键词无法创建，大概率是命中了黑名单。

## 注意事项

- 图片按编号自动命名（1、2、3……），删除中间编号后，后续投稿会**自动补上空缺编号**；
- 支持的图片格式：jpg / jpeg / png / gif / webp；
- `#add` 时消息里必须带图（直接附图或引用带图消息），否则机器人会提示；
- 直接触发采用的是**整条消息精确匹配**：消息恰好是某个关键词（或别名 + 可选编号）时才会触发，不会误伤普通聊天；
- 群聊中使用 `#` 命令通常需要先 @Hikari；开启免@后可直接发送，参见[使用须知](/start/qqbot)。

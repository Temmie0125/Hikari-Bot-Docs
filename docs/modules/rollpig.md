# 今日猪猪

每天抽一只属于你的小猪：发送 `#今日小猪`，机器人随机抽出一只有趣的小猪，并附上它的专属分析与吐槽；重复抽到同一只小猪还会**升级**（如【猪堡包】Lv.2）。所有抽到过的小猪都会记入你的**猪圈**图鉴——目标只有一个：集齐全部猪猪！

## 命令列表

| 命令 | 说明 |
| ---- | ---- |
| `#今日小猪` | 抽取今天属于你的小猪（每人每天一次）。别名：`#今日猪猪`、`#今天是什么小猪` 等 |
| `#猪圈` | 查看自己的猪猪图鉴与收集进度。别名：`#猪猪图鉴` |
| `#猪圈 @某人` | 代查他人的猪猪图鉴（群内可用，频道内不支持代查） |
| `#随机小猪 [数量]` | 从 PigHub 随机获取猪猪图，数量 1~20，默认 1 |
| `#找猪 <关键词>` | 从 PigHub 模糊搜索猪猪图，如 `#找猪 黑猪`（`#搜猪` 同义） |

## 示例

### 抽取今日小猪

```txt
@Hikari #今日小猪
→ 今天已经抽过啦，这是你的今日小猪~
[猪猪图片]【烤猪】
生活终于对我下手了
```

在官方 QQ Bot 中，回复还会附带快捷按钮 **👑猪圈** / **🐷今日猪猪**，点击即可跳转查看：

## 收集与升级

- 每天首次 `#今日小猪` 随机抽取一只小猪并记入猪圈；当天重复发送会返回同一只；
- 抽到重复的小猪会**升级**：第 1 次抽到为 Lv.1，第 2 次为 Lv.2……猪圈中以角标显示；
- 猪圈还会展示你的**本命猪**——抽到次数最多的那只。

## 注意事项

- `#随机小猪`、`#找猪` 的图片来自 [PigHub](https://pighub.top/)，每日 0 点刷新缓存；它们仅供分享，**不参与**猪圈收集；
- 官方 QQ Bot 下回复以 Markdown 消息附按钮呈现，其他平台自动回退为普通图片回复。

# 课表管理

基于自研的 [Schedule 课程表插件](https://github.com/Temmie0125/Yunzai-Schedule-Plugin)，提供课程表的导入、查询、推送订阅、快速调课等功能，并内置**生日管理**模块。课表数据与 QQ 账号绑定，**所有群通用**，无需每个群单独设置。

## 导入课表

| 命令 | 说明 |
| ---- | ---- |
| `#导入课表` | 按提示导入课表，支持 ICS 日历文件、星链课表口令、拾光课程表 JSON、Wakeup 备份文件 |
| `#设置课表 <星链口令>` | 直接通过星链课表口令设置 |

::: tip 推荐使用拾光课程表
WakeUP 课程表已封锁第三方口令导入，推荐迁移至[拾光课程表](https://github.com/XingHeYuZhuan/shiguangschedule)：在 WakeUP 中将课表导出为日历文件或备份文件 → `#导入课表` 导入 → `#导出拾光课表` 导出为拾光格式 JSON，之后即可直接使用拾光的分享口令。
:::

::: warning 课表隐私
在群聊内导入课表可能将你的课表数据暴露给群友（如「群友在上什么课」功能）：群内通过口令导入时机器人会尝试自动撤回口令；通过文件导入/导出时需要发送「确认」二次确认。详见[隐私政策](/about/privacy)。
:::

## 查询课表

| 命令 | 说明 |
| ---- | ---- |
| `#今日课表` / `#明日课表` | 查询今天 / 明天的课表 |
| `#我的课表` | 查看个人课表信息 |
| `#本周课表` / `#下周课表` / `#上周课表` | 按周查询 |
| `#第N周课表` | 查询指定教学周 |
| `#课表查询 <日期>` | 任意日期查询，支持自然语言输入 |

## 群友互动

| 命令 | 说明 |
| ---- | ---- |
| `#群友在上什么课` | 围观群友当前的上课状态 |
| `#所有人在上什么课` | 查看全体群友课表 |
| `#翘课` / `#取消翘课` | 标记 / 取消翘课状态（群内小互动） |

## 个性化设置

| 命令 | 说明 |
| ---- | ---- |
| `#课表设置昵称 <昵称>` | 自定义课表中的昵称 |
| `#课表设置签名 <签名>` | 自定义课表签名 |
| `#学期开始日期 <日期>` / `#对齐课表` | 设置学期起始，自动计算当前周数 |
| `#设置时间表` | 自定义每节课的作息时间 |
| `#调课 <内容>` / `#撤销调课` | 快速临时调课 |
| `#导出拾光课表` | 导出为拾光课程表 JSON |
| `#清除课表` | 清除自己的课表数据 |

## 推送与提醒

推送均通过**私信**发送，需要先添加机器人为好友：

| 命令 | 说明 |
| ---- | ---- |
| `#开启课表订阅` / `#关闭课表订阅` | 订阅后每天推送明日课表 |
| `#开启上课提醒 [分钟]` / `#关闭上课提醒` | 每节课开始前私信提醒，提前量 5~60 分钟可调 |

## 生日管理

插件内置生日模块：设置生日后，机器人会在你生日当天，向你**所在群聊**和**私信**尝试送上生日祝福。

| 命令 | 说明 |
| ---- | ---- |
| `#设置生日 <日期>` | 设置自己的生日 |
| `#我的生日` | 查看已设置的生日 |
| `#生日设置昵称 <昵称>` | 设置祝福中使用的昵称 |
| `#生日列表` / `#全部生日列表` | 查看本群 / 全部生日记录 |
| `#清除我的生日` | 清除自己的生日 |
| `#添加生日 <成员> <日期>` / `#修改生日` / `#移除生日` | 为群成员管理生日（管理员） |

::: warning 生日祝福需要主动消息权限
生日祝福属于**主动消息**：需要群主在群机器人设置中开启「机器人主动在群聊内发言」，且你需要添加机器人为好友才能收到私信祝福。未开通权限或推送额度耗尽时，祝福可能无法送达。设置方法见[使用须知](/start/qqbot)。
:::

## 注意事项

- 完整命令以 `#课表帮助` 和 `#生日帮助` 的输出为准；
- 课表数据存储在服务器本地，仅用于提供本模块功能（参见[隐私政策](/about/privacy)）；
- 学期结束后查询会友好提示，设置正确的学期开始日期可获得准确的周数。

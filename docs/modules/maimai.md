# 音游查分 · 舞萌DX（maimai）

基于自研的 [mai-plugin](https://github.com/Temmie0125/mai-plugin)（移植自 [nonebot-plugin-maimaidx](https://github.com/Yuri-YuzuChaN/nonebot-plugin-maimaidx) 并按 Yunzai 生态本地化重写）实现，提供 B50 查询、曲目检索、分数线、完成表、猜曲游戏等丰富功能。

指令前缀 `#` 或 `/` 均可触发，发送 `#mai help` 可查看完整帮助图。

## 绑定

::: tip 推荐 OAuth 授权
「在查分器官网绑定 QQ 号」仅水鱼查分器支持，且**官方 Bot 场景不适用**（官方 Bot 无法获取你的 QQ 号）。因此推荐并优先使用 OAuth 授权绑定，选择自己常用的查分器即可：

| 命令 | 说明 |
| ---- | ---- |
| `#mai bind df` | 发起**水鱼查分器** OAuth 授权 |
| `#mai bind lxns` | 发起**落雪查分器** OAuth 授权（全功能） |

其他绑定与解绑方式：

| 命令 | 说明 |
| ---- | ---- |
| `#mai bind fc [好友码]` | 免 OAuth 轻量绑定（落雪好友码）：可查 B50 / AP50 / 单曲，不带参数时按 QQ 自动解析 |
| `#mai bind qq <QQ号>` | 主动补充游戏 QQ，解锁水鱼按 QQ 代查（官方 Bot 场景按需使用） |
| `#mai unbind <lxns\|df\|qq>` | 解除对应绑定 |
| `#mai source` | 查看当前数据源 |

::: note 全量成绩需要落雪 OAuth
拟合b50、随心配、完成表、理论列表等**全量成绩**功能需要 `#mai bind lxns` 授权——开发者接口只提供不含达成率的简化成绩，授权后才能完整获取。`bind fc` 好友码绑定需在落雪「账号设置 → 隐私设置」中开放玩家信息 / 谱面成绩 / 历史成绩的读取权限。
:::

## 查分命令

| 命令 | 说明 |
| ---- | ---- |
| `#mai b50` | 查询 B50 |
| `#mai ap50` | 查询 AP50 |
| `#mai update` | 刷新本人成绩缓存（人人可用） |
| `#mai score <曲名>` | 查询单曲成绩 |
| `#mai myrank` | 查询自己的查分器排行 |

**随心配b50**：按条件定制的 B50（部分支持 @ 他人），分支丰富——`FC50` / `FC+50` / `单刷50` / `拼机50`（SP50）/ `FS50` / `FDX50`（FSD50）/ `东方50` / `DX50` / `红谱50` 等，发送 `#mai 随心配 帮助` 查看全部分支（出专题图）。`歌50` 还支持模拟参数，例如 `歌50 白潘 理论`、`歌50 白潘 99.00 FDX dx1145 AP`——给了达成率或评级即为纯模拟，没打过的曲也能出图。

## 曲目检索

| 命令 | 说明 |
| ---- | ---- |
| `#mai song <曲名\|ID>` | 精确查询并返回曲目详情卡 |
| `#mai search <关键词>` | 曲目检索并返回列表 |
| `#mai what <词>` | 通过别名查歌 |

`search` 检索语法：`定数14+`、`定数14-15`、`bpm200-300`、`物量300-500`（区间用 `-` 或 `~`，尾部数字为页码）。

## 分数线与完成表

| 命令 | 说明 |
| ---- | ---- |
| `#mai fsline [难度色]<曲名> [达成率]` | 分数线成图（四张表全由物量推出；难度色与曲名顺序可互换） |
| `#mai table <定数>` | 指定定数的完成表 |
| `#mai plate <条件或版本称号>` | 版本称号完成表（称号位支持「大将」，如 `#mai 堇大将完成表` = 评级 ≥ SSS+） |
| `#mai progress` | 推进度 |
| `#mai list <关键词>` | 成绩列表（支持 `list 理论(AP+)`、`list 新歌`、`list 旧版本`，按 Rating 降序） |

## 娱乐与其他

| 命令 | 说明 |
| ---- | ---- |
| `#mai guess` / `#mai guessill` / `#mai letter` | 猜曲 / 猜曲绘 / 开字母（游戏中 `#mai tips` 提示、`#mai ans` 答案） |
| `#mai fortune` | 今日舞萌 |
| `#mai rand <定数或区间>` | 随机选曲，如 `rand 13`、`rand 13-14` |
| `#mai calc <定数> <达成率>` | 单曲 Rating 计算器（免绑定） |
| `#mai alias <词>` | 查询曲目别名（支持 `alias apply` 申请别名、`vote` 参与投票） |

还保留了一批口语指令（无需前缀）：`今天mai什么`、`来个紫14`、`今日舞萌`、`XX是什么歌`、`我要上20分`、`XX有什么别名`、`真极完成表` 等。

群管理员可使用 `#mai push on|off` 开关本群别名推送；插件更新、曲库同步等管理命令仅维护者使用，此处不列出。

## 注意事项

- 完整命令以 `#mai help` 的帮助图为准，本页仅收录常用部分；
- 成绩数据由查分器提供，街机端成绩上传与查分器同步存在延迟；
- 数据只读：机器人不会登录你的街机账号，也不会修改任何账号数据；
- 查询频率过高可能触发限制，请合理使用。

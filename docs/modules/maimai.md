# 音游查分 · 舞萌DX（maimai）

查询舞萌DX 的成绩与rating数据。成绩数据来自第三方查分器（[水鱼查分器](https://maimai.diving-fish.com/) / [落雪查分器](https://maimai.lxns.net/)），机器人只读取数据，**不会实际登录你的街机账号，也不会修改任何账号数据**。

## 绑定

两种方式任选其一：

### 方式一：查分器官网绑定

自行在[水鱼查分器](https://maimai.diving-fish.com/)或[落雪查分器](https://maimai.lxns.net/)官网注册并绑定 QQ 号，机器人即可通过 QQ 号查询你在查分器中已公开或已授权的数据。

### 方式二：OAuth 授权

发送 `#mai bind`，按机器人提示完成 OAuth 授权，无需在查分器官网操作。

## 注意事项

- 数据由查分器提供，查分器侧的数据同步状态会影响查询结果；
- 查询频率过高可能触发限制，请合理使用。

# 音游查分 · Milthm

查询 Milthm 的成绩与游戏数据。数据来自[官方接口](https://milkloud.milthm.cn/)或你主动上传的游戏存档，机器人**只读取相关数据，不会对任何游戏数据进行更改**。

## 绑定与授权

| 命令 | 说明 |
| ---- | ---- |
| `#mil help` | 查看 Milthm 模块帮助 |
| `#mil bind OIDC` | 通过 OIDC 授权绑定 Milthm 账号 |

也可以直接上传游戏存档文件或提供 Access Token 授权查询，数据均来自你的主动提供。

## 注意事项

- 使用 OIDC 授权或提供 Token 前请确认来源可信，Access Token 请勿泄露给他人；
- 查询频率过高可能触发限制，请合理使用。

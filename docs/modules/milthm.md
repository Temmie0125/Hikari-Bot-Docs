# 音游查分 · Milthm

基于自研的 [mil-plugin](https://github.com/Temmie0125/mil-plugin) 实现，支持 B20 分表、单曲成绩、曲目图鉴、定数表、猜曲游戏等 Milthm 相关查询功能。

## 数据来源：在线授权与本地存档

插件支持两种数据来源，二者可以共存：

| 模式 | 说明 |
| ---- | ---- |
| **OIDC 在线授权** | 绑定 [Milkloud](https://milkloud.milthm.cn/) 云存档，自动拉取**在线成绩**，Token 自动续期 |
| **本地存档导入** | 将游戏存档文件（`.db`）直接发送给机器人导入 |

两者的关系：

- **绑定 OIDC 后，成绩表优先使用在线数据**；本地存档仅用于补充详细判定与离线回退；
- 由于 Milthm 的游戏机制，**登录后只计算在线成绩**，因此插件返回的成绩表**可能与你的游戏存档不一致**——遇到这种情况，请前往 [Milkloud 官网](https://milkloud.milthm.cn/)确认在线存档状态。

## 绑定与授权

| 命令 | 说明 |
| ---- | ---- |
| `#mil bind OIDC` | 通过 OIDC 流程授权 Milkloud 云存档（**推荐**，Token 自动续期） |
| `#mil bind <token>` | 使用 API 令牌直接绑定 |
| `#mil tk help` | 查看 Token 获取指引 |
| `#mil unbind` | 解除在线授权（**不删除**已导入的本地存档） |

::: warning Token 安全
API 令牌是敏感信息，建议**私聊**机器人进行绑定。部分配置下群聊中的 Token 绑定会被直接拒绝（含 Token 的消息可能被自动撤回并标记拒用），请重新创建令牌后私信绑定。
:::

### 本地存档导入

未绑定在线账号时，也可以直接把游戏存档文件（`.db`）作为文件发送给机器人完成导入；已绑定 OIDC 的用户同样可以导入，用于补充判定数据。发送 `#mil 删除存档` 可删除已导入的本地存档。

## 常用命令

| 命令 | 说明 |
| ---- | ---- |
| `#mil help` | 查看完整命令帮助 |
| `#mil b20` | 查询 B20 分表 |
| `#mil score <曲名>` | 查询单曲成绩 |
| `#mil recent` | 查询最近成绩 |
| `#mil data` | 查询个人数据统计 |
| `#mil update` | 拉取最新在线存档 |
| `#mil p / ap [页码]` | AP 成绩列表 |
| `#mil calc <定数> <达成率>` | 单曲 Rating 计算器（免绑定） |

## 曲库与工具

| 命令 | 说明 |
| ---- | ---- |
| `#mil table` | 查看定数表 |
| `#mil 曲 <曲名>` | 曲目图鉴查询 |
| `#mil 曲绘 <曲名>` | 查看曲绘 |
| `#mil alias <词>` | 查询曲目别名，`#mil 设置别名 <曲名> <别名>` 贡献别名 |
| `#mil myset` | 个人设置 |

另有猜曲游戏（出题 / 翻开 / 提示 / 答案）等群娱乐功能，完整列表以 `#mil help` 输出为准。

## 注意事项

- 成绩表可能与游戏内存档不一致，原因与处理方式见[数据来源](#数据来源在线授权与本地存档)一节；
- Access Token 等凭据请妥善保管，勿泄露给他人；
- 查询频率过高可能触发限制，请合理使用。

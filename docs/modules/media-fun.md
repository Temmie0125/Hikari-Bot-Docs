# 媒体解析与娱乐

链接解析与群娱乐功能合集：网易云点歌与解析、B 站视频解析、表情包制作、24 点游戏、每日打卡等。

## 媒体解析

### 网易云音乐（netease-music）

| 命令 | 说明 |
| ---- | ---- |
| `#点歌 <歌名>` | 搜索歌曲并返回选歌列表（`#网易云点歌` 等写法均可） |
| `#网易云下一页` | 选歌列表翻页 |
| `#网易云解析 <链接>` | 解析网易云音乐的分享链接 |
| `直发分享卡片` | 解析目标单曲 |
| `#无损解析 <链接>` | 无损音质解析 |
| `#网易云帮助` | 查看本模块完整帮助 |

::: info 音乐解析卡片
卡片上会出现“下载音乐”和“下载封面”两个按钮，点击即可自行下载。群聊内每个按钮点完即过期，无需重复下载。
:::

### B 站解析

自动识别聊天中的 **B 站视频链接（b23.tv 短链 / bilibili 链接）与小程序卡片**，解析并返回视频内容或信息，无需命令，直接发送链接即可。

::: info B站解析卡片
解析卡片会出现下载封面和原始地址按钮。如果视频过大不会自动下载，你可以点击下载视频按钮手动下载。
:::

## 娱乐互动

### 表情包制作

基于 meme-generator 的表情包生成，内置大量模板：

| 命令 | 说明 |
| ---- | ---- |
| `#表情包帮助` | 查看全部模板与用法 |
| `#表情包列表` | 浏览模板列表（支持页码） |
| `#表情包搜索 <关键词>` | 搜索模板 |
| `#表情包详情 <模板名>` | 查看模板用法与参数 |
| `#随机表情包` | 随机来一张 |

### 24 点游戏

| 命令 | 说明 |
| ---- | ---- |
| `#24点` | 开始一局 24 点（可用四个数字凑出 24） |
| `#回答 <算式>` / `#解 <算式>` | 提交你的答案 |
| `#结束24点` | 结束当前对局 |

### 每日打卡

发送 `#打卡` 或 `#每日打卡` 完成每日签到，坚持打卡记录连续天数。

### 答案之书

发送 `#答案之书 <问题>`，在心中默念你的问题，翻开属于你的那一页答案。

## 注意事项

- 链接解析依赖平台消息审核，部分分享卡片可能无法到达机器人；
- 表情包、无损解析等功能涉及外部服务，偶发失败可稍后重试；
- 查询与生成频率过高可能触发限制，请合理使用。

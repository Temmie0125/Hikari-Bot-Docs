# 其他功能

一些单命令的小工具与趣味功能，收录于此以便查阅。

| 命令 | 说明 |
| ---- | ---- |
| `#ping` | 测试机器人响应：回复 `pong！` 并附带处理耗时（含官方接口延迟），也可用于确认服务状态 |
| `#feedback <内容>` | 发送反馈。输入你想要的内容即可发送反馈，开发者会不定期查看。当然加入[官方群](/about/)直接反馈更方便 |
| `#选择 <选项1> <选项2> …` | 选择困难症救星：从给定选项中随机帮你选一个（`#选择 猫 狗`、`#roll 去不去`） |
| `<name>什么杯` | 模仿血狼破军的杯级评价体系，对指定内容“认真分析”（仅供娱乐） |
| `<name>男的女的` | 看看指定内容的性别（仅供娱乐，当前内置50+种性别列表，可使用`#性别列表`查看） |
| `#水群榜` | 看看当前群内的发言榜单。 |

更多细碎功能会随版本更新陆续收录。也欢迎在[官方群](/about/)提出你想看到的小工具。

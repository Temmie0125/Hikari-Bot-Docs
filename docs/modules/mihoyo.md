# 米哈游查询（原神 / 星穹铁道 / 绝区零）

米哈游系游戏查询基于两款插件实现：

- **原神 / 崩坏：星穹铁道**：[miao-plugin](https://github.com/yoimiya-kokomi/miao-plugin)，提供角色面板、角色查询、伤害计算、抽卡记录等功能；
- **绝区零**：[ZZZ-Plugin](https://github.com/ZZZure/ZZZ-Plugin)，提供面板更新、伤害计算、调频记录、活动日历等。

## 命令头约定

三款游戏使用**不同的命令头**，请注意区分：

| 游戏 | 命令头 | 示例 |
| ---- | ------ | ---- |
| 原神 | `#` | `#更新面板` |
| 崩坏：星穹铁道 | `*` | `*更新面板` |
| 绝区零 | `%` | `%更新面板` |

::: tip 绝区零命令头兼容
绝区零的 `#`、`%`、`/` 三种前缀均可触发（也可加 `zzz` / `绝区零` 前缀词），因此 `#zzzhelp` 与 `%zzzhelp` 等效。
:::

详细帮助可分别通过 `#喵喵帮助` 与 `#zzzhelp` 查看。

## 绑定 UID 与账号

面板查询前需要先绑定对应的游戏账号：

| 命令 | 说明 |
| ---- | ---- |
| `#绑定 <UID>` | 绑定原神 UID |
| `*绑定 <UID>` / `#星铁绑定 <UID>` | 绑定星穹铁道 UID |
| `#扫码登录` | 绑定米游社账号（扫码授权，自动关联 Cookie / stoken） |

- 原神与星穹铁道的 UID 相互独立、分别绑定；绑定后即可使用对应游戏的更新面板、面板查询等命令；
- **绝区零与上述游戏共用同一套米游社账号体系**（UID 随账号自动关联），完成账号绑定后即可查询；
- 绝区零如遇 10041 等接口报错，可尝试 `%绑定设备`，具体方法发送 `%绑定设备帮助` 查看；
- 绝区零 Cookie 失效时可发送 `#刷新ck` 重新授权。

## 原神 / 星穹铁道（miao-plugin）

| 命令 | 说明 |
| ---- | ---- |
| `#更新面板` / `*更新面板` | 从米游社拉取并更新展柜角色的面板数据 |
| `#<角色名>面板` / `*<角色名>面板` | 查看角色详细面板（属性、词条、配装、伤害计算） |
| `#<角色名>` | 查看角色卡片 |

此外还支持今日素材、抽卡记录分析、角色别名等功能，完整列表见 `#喵喵帮助`。

::: info 戳一戳功能不可用
原插件支持的戳一戳互动依赖平台戳一戳事件，**官方 Bot 场景暂不支持**该事件，因此相关功能无法使用。
:::

## 绝区零（ZZZ-Plugin）

| 命令 | 说明 |
| ---- | ---- |
| `%更新面板` / `%更新展柜面板` | 拉取并更新展柜角色的面板数据 |
| `%<角色名>面板` | 查看角色详细面板 |

此外还支持伤害计算、调频（抽卡）记录、活动日历、兑换码查询等，详细帮助见 `#zzzhelp`。

## 绑定与隐私

- **公开数据查询**：角色面板等展柜数据为公开信息，绑定 UID / 账号后即可查询；
- **账号绑定（可选）**：通过 `#扫码登录` 绑定米游社账号（或手动绑定 Cookie / stoken）后，可使用全量刷新、体力、签到、抽卡记录等非公开数据功能。Cookie 属于敏感凭据，手动绑定方式下**务必通过私聊发送**，切勿在群聊中透露，详见[隐私政策](/about/privacy)。

## 注意事项

- 面板数据来自米游社等接口，游戏内更新后存在同步延迟，可重新执行更新命令刷新；
- 查询与更新频率过高可能触发限制，请合理使用；
- 三款游戏命令头不同，如果命令没有反应，先检查命令头是否正确。

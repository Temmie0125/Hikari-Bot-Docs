# 开始使用

本页介绍如何开始使用本机器人。机器人提供的是**公开托管服务**，你不需要（也无法）自行部署，按下面步骤加入使用即可。

## 它是什么？

- 一个运行在 QQ 官方机器人平台上的**群机器人**；
- 底层基于 [Yunzai Bot](https://github.com/TimeRainStarSky/Yunzai) 构建并封装，提供查分、娱乐、工具等多种功能模块；
- 由维护者统一部署和运维，用户只需加群、发命令。

## 三步开始

::: tip 流程总览
① 加入官方群 → ② @Hikari 或发送命令 → ③ 对照文档使用
:::

### ① 加入官方群

在 QQ 搜索机器人，或通过群聊卡片添加机器人为好友/群成员。官方交流群号见 [关于页面](/about/)。

### ② 发送第一条命令

在聊天中 @Hikari 并发送命令，例如：

```txt
@Hikari 帮助
```

::: tip 免 @ 使用
群主在群设置中开启「获取群内全部消息」后，群里无需 @Hikari、直接发送命令即可触发，详见[QQ 官方 Bot 使用须知](/start/qqbot)。
:::

**快捷命令菜单**：除了手动 @Hikari，还可以在聊天窗口的输入框中输入 `/`，唤起快捷命令菜单，点选即可快速填入常用命令：

![在聊天输入框输入 / 唤起 Hikari 的快捷命令菜单](/images/quick-command.png)

::: warning 菜单仅收录常用命令
受官方快捷菜单的条目限制，菜单中只列出了常用命令。更多命令请参阅本站[功能模块](/modules/)文档，或使用各模块的子帮助命令（如 `phi help`、`mil help`）查询后手动输入完整指令。
:::

机器人会以消息 + **按钮** 的形式返回功能菜单，点击按钮即可进一步交互。

### ③ 对照文档使用

左侧目录按功能模块组织，每个模块页面包含：功能简介、命令列表、使用示例、注意事项。也可以直接用右上角搜索框（`Ctrl + K`）搜索命令。

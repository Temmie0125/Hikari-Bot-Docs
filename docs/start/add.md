# 添加须知

当前 QQ 官方平台**暂不开放私聊添加**（无法将 Hikari-Bot 添加为好友），机器人加群也存在一定限制条件。因此，Hikari-Bot 目前采取**【半公开】的内邀制加群**：

- 只想体验功能：直接[加入官方群](/about/)即可使用；
- 想将机器人添加到**自己的群聊**：请确认满足下方要求后联系 Bot 主。

## 申请要求

如果你想要将机器人添加到自己的群里，请确认满足以下全部要求后，联系 Bot 主（**Temmie**，QQ `1179755948`，[点击私聊](https://qm.qq.com/q/foU9nZ6wg2)）：

1. **群聊人数 ≥ 50 人**；
2. **群内有至少 2 项功能需求**（如米游查询、音游查分、娱乐功能，以[功能模块](/modules/)文档为分类）；
3. **你必须为该群群主**。

::: info 联系时请一并说明
- **群聊主要成分**（群里主要聊什么、什么圈子）；
- **需要添加 Hikari-Bot 的理由**；
- **群内人数**。
:::

## 审核流程

::: tip 流程总览
① 满足要求并联系 Bot 主 → ② 初步核实 → ③ Bot 主入群审核 3 天 → ④ 设为管理员，拉入机器人
:::

1. **初步核实**：Bot 主确认信息满足要求后，会**加入你的群聊进行为期 3 天的审核**，主要审查群内聊天氛围；
2. **审核通过**：Bot 主审核完成后会联系你，届时需要**将 Bot 主设为群管理员**，由 Bot 主将机器人拉入群聊；
3. 拉入成功后，按[开始使用](/start/)的指引即可体验各项功能。

::: warning 管理员可以只临时设置
官方平台限制：机器人只能拉入「**拉取人是管理员**」的群聊。因此将 Bot 主设为管理员**临时设置也可以**——机器人拉入群聊后，撤掉管理员身份也不影响机器人正常使用。
:::

## 特别注意

::: danger 请勿将 Bot 主移出群聊
机器人与 Bot 主的入群状态绑定：**请勿将 Bot 主直接移出群聊，否则机器人会被连带移除**。
:::

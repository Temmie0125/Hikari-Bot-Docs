# QQ 官方 Bot 使用须知

本机器人接入的是 **QQ 官方机器人平台**（而非个人号协议），因此消息行为与普通 QQ 用户不同。使用前请了解以下平台规则，能避免绝大多数「机器人没反应」的问题。

## 群聊调用：@ 或免@

- 默认情况下，群聊中需要 **@ 机器人**再跟命令词，例如 `@机器人 查分`；
- **好友单聊**中无需 @，直接发送命令即可。

### 开启免@（推荐群主设置）

官方 Bot 支持在群聊内开启「接收全部消息」，开启后**无需 @**，直接发送命令即可触发机器人：

1. 由**群主**打开 **群设置 → 群机器人**，点击本 Bot 的头像进入设置页；
2. 在 **「机器人可获取的群聊消息范围」** 中选择 **「获取群内全部消息」**；
3. 如需允许机器人**主动推送**消息（如定时任务、订阅提醒），还需打开 **「机器人主动在群聊内发言」** 开关。

![QQ 群机器人设置：消息范围选择「获取群内全部消息」，并打开「机器人主动在群聊内发言」](/images/group-message-guide.png)

::: tip
消息范围另有「获取@机器人的最近10条消息」「仅获取@机器人的消息」两档，保持默认时机器人只能看到 @ 它的消息。开启全部消息后，机器人才能支持关键词直触（如[名场面](/modules/famous)的关键词调用）等免@功能。
:::

## 回复与频率限制

官方平台对机器人发消息有明确的次数限制：

- 机器人一般只能**回复**用户消息，主动推送受限制（需群主开启上述开关）；
- **回复上限**：群聊内每条消息最多回复 **5 次**，私聊每条消息最多回复 **4 次**；
- 通常一条命令只对应一条回复，正常使用**不会触及上限**；单个功能需要多条回复时（如图片 + 按钮），也在限制之内。

## 消息延迟

官方 Bot 接口存在调用延迟，「偶发延迟」是**已确认的平台特性**，不是机器人掉线。如果想确认机器人状态，可以发送：

```txt
#ping
```

机器人会回复 `pong！` 并附带**处理耗时**（该耗时包含官方接口的调用延迟）。能收到 pong 回复即说明服务正常。

## 消息审核

通过官方平台发送的内容可能经过安全审核：

- 含敏感词或图片的消息可能被平台拦截，机器人不会收到或无法回复；
- 偶发延迟或吞消息属正常现象，不要连续快速重复发送同一命令。

## 按钮交互

机器人大量使用**消息按钮**进行交互：

- 列表、翻页、确认等操作优先用按钮完成，点击按钮等效于发送对应命令；
- 按钮有时效，过期后按钮不可点击，重新发送命令即可；
- 在不支持按钮的客户端/场景下，机器人会尝试以文字提示替代。

## 支持的客户端场景

| 场景 | 支持情况 | 备注 |
| ---- | -------- | ---- |
| 群聊 @ 机器人 | ✅ | 默认可用，无需额外设置 |
| 群聊免@直接发送 | ✅ | 需群主开启「获取群内全部消息」，见上文 |
| 好友单聊 | ✅ | 无需 @，直接发送命令 |
| QQ 频道 | ❌ | 适配器已支持，但本 Bot 暂无接入频道的计划 |

## 常见「不回消息」排查

1. 群聊中是否 **@ 了机器人**？或群主已开启[免@](#群聊调用-或免)后直接发送；
2. 命令格式是否正确？对照[功能模块](/modules/)页面的示例；
3. 怀疑延迟或掉线？发送 [`#ping`](#消息延迟) 测试，有回复即服务正常；
4. 是否触发了消息审核拦截？换一种表述或稍后再试；
5. 仍无响应请到官方群反馈，附上发送的命令截图。

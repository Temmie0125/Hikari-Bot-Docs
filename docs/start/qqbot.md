# QQ 官方 Bot 使用须知

本机器人接入的是 **QQ 官方机器人平台**（而非个人号协议），因此消息行为与普通 QQ 用户不同。使用前请了解以下平台规则，能避免绝大多数「机器人没反应」的问题。

## 消息机制差异

### 消息需要 @ 机器人

- 在**群聊**中，绝大多数命令需要先 **@ 机器人**再跟命令词，例如 `@机器人 查分`；
- 在**单聊（好友会话）**中通常无需 @，直接发送命令即可。

### 主动消息与回复限制

官方平台对机器人发消息有频率和时效限制：

- 机器人一般只能**回复**用户消息，主动推送受严格限制；
- 部分场景下消息有条数上限（如每条用户消息可回复的条数）；
- 超出限制时机器人可能表现为「已读不回」，属正常现象，稍后再试即可。

### 消息审核

通过官方平台发送的内容可能经过安全审核：

- 含敏感词或图片的消息可能被平台拦截，机器人不会收到或无法回复；
- 偶发延迟属正常，不要连续快速重复发送同一命令。

## 按钮交互

机器人大量使用**消息按钮**进行交互：

- 列表、翻页、确认等操作优先用按钮完成，点击按钮等效于发送对应命令；
- 按钮有时效，过期后按钮不可点击，重新发送命令即可；
- 在不支持按钮的客户端/场景下，机器人会尝试以文字提示替代。

## 常见「不回消息」排查

1. 是否 **@ 了机器人**（群聊场景）？
2. 命令格式是否正确？对照[功能模块](/modules/)页面的示例；
3. 是否触发了频率限制？等待 1~2 分钟再试；
4. 是否为消息审核拦截？换一种表述或稍后再试；
5. 仍无响应请到官方群反馈，附上发送的命令截图。

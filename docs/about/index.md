# 关于 Hikari-Bot

## 简介

**Hikari-Bot** 是基于 [Yunzai Bot](https://github.com/TimeRainStarSky/Yunzai) 构建并封装的 QQ 官方平台机器人，提供音游查分、游戏数据查询、课表管理、媒体解析、娱乐互动等多种功能，以**公开托管服务**形式运营——无需自行部署，加入官方群即可使用。

## 加入官方群

| 项目 | 信息 |
| ---- | ---- |
| 官方交流群 | [点击入群](https://qm.qq.com/q/vpZUuRg2yI)（入群问题答案见群简介） |
| 机器人好友 | 暂不支持添加，敬请期待；可先访问 [Bot 主页](https://bot.q.qq.com/s/vQXzOmYv04) |

::: tip
入群后请先阅读群公告，再按照[开始使用](/start/)的指引体验各项功能。
:::

::: info 想把机器人添加到自己的群聊？
Hikari-Bot 对外群目前采取【半公开】的内邀制加群：确认满足条件后可联系 Bot 主申请，详见[添加须知](/start/add)。
:::

## 反馈与建议

发现功能异常或有新功能建议时，可通过以下任一渠道联系我们：

- **官方群反馈**：在[官方群](https://qm.qq.com/q/vpZUuRg2yI)内反馈，附上发送的命令、机器人回复（或无响应现象）及大致时间，便于复现和定位（参见[常见问题](/start/faq)）；
- **`#feedback` 命令**：通过机器人直接提交反馈；
- **联系开发者**：[QQ 私聊](https://qm.qq.com/q/foU9nZ6wg2)，或发送电子邮件至 `1179755948@qq.com`，注明来意并附相关截图。

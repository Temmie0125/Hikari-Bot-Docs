## 简介

本机器人是基于 [Yunzai Bot](https://github.com/TimeRainStarSky/Yunzai) 构建并封装的 QQ 官方平台机器人，提供音游查分、娱乐互动等多种功能，以**公开托管服务**形式运营——无需自行部署，加入官方群即可使用。

## 加入官方群

| 项目 | 信息 |
| ---- | ---- |
| 官方交流群 | `QQ 群号待填写` |
| 机器人好友 | `QQ 号待填写`（搜索添加） |

::: tip
入群后请先看群公告，再阅读[开始使用](/start/)。
:::

## 反馈与建议

- 功能异常：在官方群反馈，附上命令与截图（参见[常见问题](/start/faq)）；
- 新功能建议：在官方群提出，或通过群文件的需求收集表提交。

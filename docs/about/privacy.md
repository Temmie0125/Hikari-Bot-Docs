# 隐私政策

最后更新日期：2026 年 8 月 12 日

本政策说明 Hikari-Bot（以下简称"我们"）如何收集、使用、存储与保护您的信息。服务条款与免责声明请见[用户协议](/about/terms)。

## 一、信息收集与使用

为提供、维护、优化服务及提升交互体验，本服务可能在以下场景收集并使用您的部分信息。**所有收集的信息均由我们部署的服务器本地存储，不会主动向任何第三方公开或出售。**

### 1.1 通用信息收集（可能用于所有功能）

- **用户头像、昵称、资料卡信息**：用于识别用户身份、提供个性化回复或上下文交互。
- **聊天记录（含群聊/私聊）**：仅在使用需要上下文理解的功能（如 AI 聊天、AI 总结）时临时读取，用于生成更贴合语境的回应。

### 1.2 各功能模块专项收集

#### （1）米哈游游戏查询（原神 / 崩坏：星穹铁道 / 绝区零）

- 必要信息：**游戏 UID**（用于获取公开游戏数据如角色面板等）。
- 可选信息：**米哈游通行证 Cookie（ck）**，用于全量刷新数据、获取抽卡记录等非公开数据。

::: warning 特别提醒
Cookie 和 sessionToken 可获取您账号下的非公开数据，请务必**通过私聊发送给机器人**，切勿在群聊中透露。如因您自行在公开场合泄露导致损失，我们不承担责任。
:::

#### （2）Phigros

- 必要信息：用户的 **TapTap sessionToken**，用于从 Phigros 云存档获取成绩数据。我们不会将您的 Token 泄露或公开给任何第三方成员或组织。如因用户主动在群聊、社交平台、第三方工具等场景泄露 Token 或 Cookie 等敏感信息，均由用户自身引起，我们不承担任何责任。
- 可选公开信息：成绩数据可能被上传至 phi-plugin-api 查分平台，用于生成排行榜、平均成绩统计等公开功能。**如您不同意成绩被公开，请勿使用该模块的成绩查询或排名功能。**

本服务与 Phigros、鸽游网络、TapTap 平台运营不存在任何官方合作关系。本服务使用的所有数据均由公开接口获取，仅对原始数据进行读取，不会修改或篡改任何游戏数据。如因官方接口或政策调整导致服务异常或中断，我们不承担任何责任。

#### （3）舞萌DX（maimai）

- 本模块所有数据来源于[水鱼查分器](https://maimai.diving-fish.com/)。用户需自行在查分器官网绑定 QQ 号，机器人仅通过 QQ 号查询已公开或用户授权的查分器数据。
- 同上，本服务数据均来源于查分器官网，我们只对数据进行读取，不会实际登录玩家的舞萌DX账号，也不会修改任何账号数据。

#### （4）课表模块

- 用户主动导入的课程表数据将存储在服务器本地。请知悉：在部分群聊功能中，他人可能通过指令获知您的部分非敏感课表信息（如"群友在上什么课"）。敏感信息（如教师姓名等）不会被主动公开，但建议用户自行评估风险后再导入。
- 课表数据来源于 Wakeup 口令（30 分钟有效）或拾光的 JSON 文件。请注意：**如果您在群聊内使用导入课表功能，您的课表数据可能会泄露给其他人员**。针对这一情况，我们会采取如下措施：
  - 在群内尝试通过口令导入时，机器人会尝试自动撤回口令；
  - 在群内尝试通过文件导入或导出时，需要您发送"确认"以进行二次确认。

如果因为用户自身原因导致课表数据泄露，我们不承担任何责任。如果您对本模块服务有任何问题，可以前往我们的 [GitHub 仓库](https://github.com/Temmie0125/Yunzai-Schedule-Plugin)了解详情。

#### （5）AI 聊天服务（基于 DeepSeek API）

- 使用该功能即视为您授权机器人读取您的 QQ 资料卡及当前对话上下文（含聊天记录），用于生成个性化、连贯的回复。
- 对话记录仅用于单次响应，不会长期存储或用于模型训练。

#### （6）AI 总结服务（群聊总结）

- 仅限本机器人的官方运营群，会收集群内的聊天记录（不含私聊），经由 DeepSeek API 生成摘要。
- 该功能旨在提升群聊信息获取效率，原始聊天记录不会对外公开。

## 二、数据存储与安全

- 所有收集的数据均存储于我们控制的服务器本地，采取常规安全措施（如防火墙、访问控制）防止数据泄露或丢失。
- 我们将采取行业标准的安全措施保护数据，但无法承诺绝对安全。若因黑客攻击、电力中断等不可抗力导致数据泄露，我们将立即公告并上报监管部门，依法承担已尽合理注意义务后的相应责任。
- **数据保留期限**：除用户主动要求删除外，一般数据（如 UID、课表）保留至您停止使用相关功能后 6 个月内自动清除；Cookie 等敏感信息在功能停用或您要求后立即删除。
